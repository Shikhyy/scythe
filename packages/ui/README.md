# @scythe/ui

Shared design tokens, typography, colors, and accessible component primitives for Scythe 3D.

## Responsibilities

- Faction color tokens and accessible contrast pairs
- Elevation, typography scale, spacing tokens, and border radii
- Motion duration and easing tokens (coordinating CSS, GSAP, and R3F)
- Accessible UI primitives (dials, tracks, resource counters, modal dialogs)
- Reduced-motion and high-contrast theme tokens

## Non-Negotiables

- **Accessibility**: Meets WCAG 2.1 AA standards; does not convey state via color alone.
- **Anti-slop**: Follows strict design guidelines (no generic purple gradients, neon borders, or clunky admin layouts).
